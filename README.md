# Café Financial Analysis Sample

An owner-friendly café financial review and supporting Excel profitability model prepared as a portfolio sample for financial analysis and modeling work.

## Files

- **Cafe_Financial_Analysis_Sample.pdf** — four-page management report covering revenue, gross margin, labour, menu profitability, break-even, operating expenses, cash flow, suppliers, and prioritized actions.
- **Cafe_Profitability_Model.xlsx** — formula-driven model with an executive dashboard and supporting schedules.

## Workbook tabs

1. Executive Dashboard
2. Revenue Analysis
3. COGS
4. Labour
5. Menu Profitability
6. Break-even
7. Expenses
8. Cash Flow
9. Recommendations

## Purpose

The sample demonstrates how POS, profit and loss, payroll, roster, supplier, menu, inventory, and cash information can be converted into practical recommendations for a café owner.

## Important disclaimer

All figures and business details in this repository are fictional and illustrative. This is a portfolio sample, not a real client engagement, and it does not claim results achieved for an actual café.
